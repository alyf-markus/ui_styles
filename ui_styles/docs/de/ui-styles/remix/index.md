# Remix

Optionale Desk-Schale unter `/remix`. Verlauf und Favoriten in der regulären Frappe-Navbar, optionale Remix-Seitenleiste mit Suche, und Remix-Farben. Der Standard-`/desk` bleibt unverändert, bis ein System-Manager Remix einschaltet.

Die Funktion ist **standardmäßig aus**. `/remix` leitet auf `/desk` um, bis *Remix aktivieren* an ist, mit *Verlauf*, *Favoriten* und/oder *Alternative Navigation*.

## Anleitungen

- [Seiteneinstellungen](/app/docs/de/ui-styles/remix/site-settings) - **Remix-Einstellungen**

Beim Speichern von **Remix-Einstellungen** wird der Cache geleert. Desk hart neu laden, um Änderungen anzuwenden.
