# Remix

Optional Desk shell at `/remix`. History and favorites in the regular Frappe navbar, optional Remix sidebar with search, and Remix colours. Standard `/desk` stays as it is until a System Manager enables Remix.

The feature is **off by default**. `/remix` redirects to `/desk` until *Enable Remix* is on, with *History*, *Favorites*, and/or *Alternative Navigation*.

## Guides

- [Site settings](/app/docs/en/ui-styles/remix/site-settings) - **Remix Settings**

Saving **Remix Settings** clears cache. Hard-refresh Desk to apply changes.
